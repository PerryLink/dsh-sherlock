# Code of conduct

Be respectful and constructive. This project is for public, lawful username reconnaissance and defense; do not use it for harassment, doxxing, stalking, or high-impact decisions about a person.

Unacceptable behavior includes threats, discriminatory language, publishing private personal data, and using the project to bypass authentication or platform protections.

Report conduct concerns privately to the maintainer through the GitHub profile. Maintainers may remove comments, close threads, or block accounts that violate these rules.
